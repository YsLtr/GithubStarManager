# 导入后不自动同步

导入完成后**不再**自动触发全量同步（推翻 `0001-export-import-format.md` 的「导入完成后直接调用同步函数」）。导入是数据搬运，落盘即完成；是否拉取远端由用户自己决定（标题行 Sync / TM 菜单）。导入本身仍会被完整同步流程正确处理：导入包里的 `repoCache` 条目先落本地缓存，若远端并不存在该 star，下一次同步的整表 diff 会把它判为本地独有，走既有的「外部取关 → 宽限期备份」管线（切片混合模式下先逐条 `GET /user/starred/{o}/{r}` 核对后才确认）。

## Considered Options

- **导入后自动 `runFullSync('button')`**（原决策）：被否决。导入结果已由 `alert` 摘要表达，再叠一条同步简报会让用户分不清两组数字；且导入的条目缺 `starredAt`（`buildLocalSlices` 的阀门 A）→ 立刻触发一次**无条件整表**拉取，对用户是意外的大请求。
- **保留自动同步但静音简报**：被否决。等于用一个不可见的写操作换用户的既定期望，比显式不同步更难解释。
