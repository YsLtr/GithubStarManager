# 分页按钮可跳页 + 所有同步入口驱动头部 Sync 按钮图标旋转(并删除整按钮刷新态死码)

> 状态:**待用户审查**(deep-plan P4)。
> 上游需求(用户原话要点):
> 1. 分页按钮当前「仅显示当前页数,点击无任何效果」→ 应利用它,**点击可输入要去的页数**。
>    目标节点:`#user-starred-repos > div > div.col-lg-9 > div.position-relative.gsm-header-row > div > div > span`
> 2. 脚本有多处 Sync 入口,部分点击后无明显回应或只是后台刷新 → **每个刷新都要反应到头部按钮**上,
>    让**按钮前面的 ICON 转起来**,而不是现在整个按钮变成刷新态。
> 3. **旧的整按钮刷新态已无使用场景,顺便删除。**

版本影响:4.9.2 → **4.10.0**(可见行为变更 + CSS 删除)。`@version` 变化 ⇒ 使用 dev 脚本者**必须重装 dev loader**。

**Verdict**: **Compose** — 旋转与加载态抄 **Primer `.anim-rotate` + Primer React `ButtonBase` loading 范式**;跳页控件抄 **`inputmode="numeric"` 文本框 + 原生 Popover 规范的降级思路**(本次实际不用 popover) — GitHub 自身**零跳页先例**、Primer `Pagination` 无跳页入参,故无单一可 Adopt 的现成方案。证据见 §2.5。

---

## 1. 范围

### 做

1. 页码指示器 `N / M` 从静态 `<span>` 升级为可点击、可聚焦的控件;点击后**原位**变成输入框,输入目标页并跳转。
2. 跳页与现有 `Previous` / `Next` **共用唯一提交口径**(夹取 + 越界守门 + `renderBrowsePage`),不各写一份校验。
3. 同步状态在 `fullSync.ts` 内**收敛为单一真相 + 订阅广播**;头部 Sync 按钮成为该状态的**唯一视图**。
4. 任意入口(TM 菜单 / 配置横幅 / Token 保存后 / 进页自动 / 按钮自身)触发的同步,都让按钮内 **octicon 旋转**,按钮文字与几何**不变**。
5. 删除旧的整按钮刷新态(`.gsm-pager-loading` 及其伪元素转圈、相关 `classList` 读写),保留并复用 `@keyframes gsm-spin`。
6. 同步**失败与被并发丢弃**留下可见痕迹(按钮 title + 短暂 error 态),不再只有 `console.error`。
7. 版本与两份文档(`DEVELOPER.md` / `AGENTS.md`)同步。

### 不做

- 不改 `runFullSync` 的签名,也不改它的 5 个调用点。
- 不为同步引入队列(整表操作排队无意义;保持「进行中则丢弃」语义)。
- 不动 `pagination.ts` 里已有的 `a[data-gsm-page]` 拦截逻辑(它的正确性已被 4.9.2 审查确认)。
- 不做移动端(<768px)的任何 UI —— 窄视口继续**完全惰性**(AGENTS D18)。
- 不碰星按钮写路径与变异队列(D10)、不碰恢复菜单、不碰导出导入。
- **不用 SVG SMIL 做动画**(理由见 §2.5,是硬禁止)。
- 不用 popover / `anchored-position` 做跳页(理由见 D1/D24)。
- 不顺手给既有其他动画补 `prefers-reduced-motion` 门(只作用于本次新增的那条规则,控制 diff)。
- 不新增 `@grant`、不新增任何依赖(`package.json` 的 dependencies 一棵都不动)。

### 2.5 联网调研结论(第三方实测/官方文档,每条给来源)

1. **GitHub 自身没有「输入页码跳页」**。抓线上 `github.com/primer/react/labels?page=2` 原始 HTML:分页块是 `<nav aria-label="Pagination" data-component="Pagination">` + 页码链接(`aria-label="Page N"`、当前页 `aria-current="page"`)+ `Previous`/`Next`(`rel="prev|next"`),**整页 `<input>` 计数 = 0**。
   <https://github.com/primer/react/blob/main/src/Pagination/Pagination.tsx>(props 仅 `currentPage` / `pageCount` / `hrefBuilder` / `marginPageCount` / `onPageChange` / `showPages` / `surroundingPageCount` / `renderPage` — **无跳页入参**)
   ⇒ 本改动是在 GitHub 页面上**引入 GitHub 没有的控件**,没有原生样式可继承,视觉只能复用既有 `.btn` / `BtnGroup` 类。
2. **`?page=N` 是 1-based,且越界不报错**。REST 文档:`per_page` 上限 100;实测网页端 `page=0` / `page=abc` 回落第 1 页,`page=999` 返回 **200 + 空结果、不 404**。
   <https://docs.github.com/en/rest/using-the-rest-api/using-pagination-in-the-rest-api>
   ⇒ **越界校验必须由本地代码负责**(本项目本就全本地分页,正好闭合)。
3. **不要用 `type="number"`**。MDN 与 APG:`type=number` 隐式角色为 `spinbutton`,方向键会意外改值,且非法输入**没有任何反馈**;推荐 `inputmode="numeric"` + `pattern`(APG Spinbutton 若用则要求 `aria-valuenow/min/max` 与越界 `aria-invalid`)。
   <https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/number#accessibility>、<https://www.w3.org/WAI/ARIA/apg/patterns/spinbutton/>
4. **Popover API 属 Baseline 2024(Safari 17+)**,而本仓库构建目标含 `cssTarget=safari15` ⇒ 用 popover 必须能力检测 + 手写降级(点击外关、Esc、焦点归还 invoker、`aria-expanded`/`aria-details`)。
   <https://developer.mozilla.org/en-US/docs/Web/API/Popover_API>、<https://caniuse.com/mdn-api_htmlelement_popover>
   ⇒ 本次跳页**不用 popover**,这条自然豁免(既有 tagFilter 等处的 popover 用法不在本次改动范围)。
5. **Enter 提交的标准做法是 `<form>` + implicit submission**(配合 `enterkeyhint="go"`);手写 keydown 属偏离。
   <https://html.spec.whatwg.org/multipage/form-control-infrastructure.html#implicit-submission>
- **「只变图标、文字不动」有官方实现可抄**:Primer React `ButtonBase` 在 loading 时**保留文字 span 不动、只把 leading/trailing visual 换成 `<Spinner size="small">`**,同时加 `aria-disabled="true"`、摘掉 `onClick`、用隐藏 live region 播报;源码注释明说**「切 loading 前后若 DOM 不同形,按钮会丢焦点」**。
   <https://github.com/primer/react/blob/main/packages/react/src/Button/ButtonBase.tsx>、<https://primer.style/foundations/accessibility/guidelines>
6. **Primer 的按钮加载态 a11y 四条**:不摘除节点、不用 `disabled` 属性;用 `aria-disabled="true"`;视觉隐藏的 `aria-live="polite"` 区域且文案**只在 loading 期间渲染**;出错时把焦点移到错误横幅标题。
7. **旋转写法定型**:抄 `.anim-rotate`(`animation: rotate-keyframes 1s linear infinite` + `transform: rotate(360deg)`),作用在**外层 `<svg>`**(有布局盒 ⇒ `transform-origin: 50% 50%` 即中心);
   <https://github.com/primer/css/blob/main/src/utilities/animations.scss>
   **禁止 SVG SMIL**:Primer PR #1251(2021-03-23)记录**无限 SMIL 会让后台标签回前台时冻结数秒甚至数分钟**的 Chrome bug —— 与本脚本既有的「后台标签冻结」观察同源。
   <https://github.com/primer/css/pull/1251>
8. **`prefers-reduced-motion` 存在规范与实现分歧**:Primer 动效指南要求包媒体查询且「>5s 的动效要可暂停」,但 **Primer CSS 的 `.anim-rotate` 自身并未包**。本方案**以官方指南文字为准**(自行包媒体查询),并以固定的按钮文字作为非动画替代(WCAG 2.2.2 Note 4 允许把加载动画视为 essential)。
   <https://primer.style/foundations/motion>

## 3. 设计(P1 自问自答的结论;决策编号为本次规划内部编号,与 AGENTS 的 D1–D21 无关)

### 3.1 分页跳页

| 决策 | 结论 | 依据 |
|---|---|---|
| **D1** 交互形态 | 点击 `N / M` → **同一单元格内**原位换成 `<input>`;Enter 提交 / Esc 取消 / blur 提交;退出即销毁输入节点、恢复按钮文本。**不用 popover,不用 `window.prompt`**(后者有阻塞主线程的实测事故) | `src/transform.ts:94-96`;popover 依赖 document 级 id,与克隆件冲突;§2.5-4 |
| **D4** 控件升级 | 指示器改为 `<button type="button" class="btn BtnGroup-item gsm-page-info">` + `title`/`aria-label`(中文,说明「点击输入页码」与当前/总页数) | 现状 span 键盘不可达;`src/ui/tagFilter.ts:44-52` 的既有约定 |
| **D19** 事件归属 | 跳页逻辑**住在 `pagination.ts`**,由那处 window-capture 委托监听(`closest('button.gsm-page-info')`)承担,**不在分页器节点上挂监听** | `cloneNode(true)` 不复制监听(`src/transform.ts:124`);避免两个挂载点两条真相 |
| **D2** 提交口径 | 新增唯一导出函数 `navigateToLocalPage(raw: unknown)`: `Number.isFinite` → 夹取 `[1,totalPages]` → 同页早退 → `renderBrowsePage(page)`;**prev/next 与新输入态都只调它** | `src/filters.ts:244-251` 对 NaN 无守卫;`src/pagination.ts:35-45` 现有校验;**§2.5-2 证明越界必须本地兜** |
| **D3** 编辑态保护 | `updateLocalPagers()` 对「当前处于输入态的**那一份**」跳过写入(判据 = 该单元格里现在是 `input` 而不是按钮) | `src/filters.ts:277-288` 会无条件覆盖 textContent |
| **D20** 提交语义 | 非数字/越界**静默夹取**,夹取后等于当前页则不跳;全程不弹提示、不显示错误文案 | 与 `src/pagination.ts:43` 的既有静默口径一致 |
| **D5** 不受拦截器干扰 | 新控件不放进 `a[data-gsm-page]` 的后代里 ⇒ `closest` 返回 null ⇒ 不 `preventDefault`;拦截器只看 `click` ⇒ 输入框按键不受影响。**不需要改拦截器的事件注册** | `src/pagination.ts:21,23-30` |
| **D12** 回滚 | 输入控件只在输入态期间存在,且位于分页器结构内部(底部随 `.stars-grid-container`、顶部随 `.gsm-top-pager` 被删)⇒ **不因跳页功能新增 teardown 选择器**;唯一例外是 **D23** 的播报区 | `src/viewTeardown.ts:47-57`;`AGENTS.md` D18/D20 |
| **D24** 不用 popover | 跳页不引入 popover/`anchored-position`:① 顶部是克隆件,overlay 与 `popovertarget` id 会被一起复制;② Popover API 是 Baseline 2024(Safari 17+),超出本仓库 safari15 的目标面 | §2.5-4;`src/transform.ts:124-126` |
| **D25** 越界本地兜 | 不依赖任何远端行为:页码在本地夹取,且 `page=999` 类请求永远不会发出 | §2.5-2;本项目全本地分页 |
| **D26** 提交监听手写 | **手写 `keydown`(Enter)而非 `<form>` implicit submission**:避免在外层可能存在的 `<form>` 内嵌套表单(非法 HTML),并加 `enterkeyhint="go"` 兼顾移动端键盘。**这是对 W3C 通用建议的自觉偏离**,记录在案 | §2.5-5;输入框是**瞬态**节点,监听随节点一起销毁 ⇒ 无泄漏、无需 teardown |

**输入框规格**(实现直接照做):

- `type="text"` + `inputmode="numeric"` + `pattern="[0-9]*"` + `enterkeyhint="go"`(**不用 `type="number"`**,依据 §2.5-3:避免 `spinbutton` 语义、方向键意外改值与「非法输入无反馈」)。

- 提交后**同时**更新顶底两份(由 `renderBrowsePage → updateLocalPagers` 天然完成)。

静态:

```bash
pnpm check                                  # tsc --noEmit + build
pnpm build && node scripts/verify-css.cjs    # 产物 CSS 与源 CSS 等价性
pnpm test:exportimport                       # 无关但便宜的回归保险(51 项断言)
```

仿真页(gitignore 工装,可重跑;两条已知的工装坑必须遵守):

- 构造 URL **必须带 `?tab=stars`**,否则 `isStarsPage()` 为假、脚本根本不转换,`grid: 0` 会被误读成「全绿」。
- 把 bundle 内联进夹具时用**函数形式** `html.replace(needle, () => text)`(产物里有 `$&` 字面量,字符串替换会展开成反向引用)。

断言项:

1. 桌面载入:网格 / 顶部翻页器 / Sync 按钮齐(回归)。
2. 点击**顶部**指示器 → 出输入框且已聚焦、已全选;输入 `999` 提交 → 落到末页;顶底两份文本都变成 `N / N`。
3. 点击**底部**指示器 → 同上(证明委托而非节点监听)。
4. 输入 `0` / `-1` / `abc` / 空 → 落到第 1 页或维持原页,**不抛错、不弹提示、不发出任何请求**。
5. 输入当前页 → 不重绘(可用卡片引用是否变化判断)。
6. 输入态下强制一次渲染 → 输入框仍在、值未丢(编辑态跳过生效)。
7. 通过桩订阅者/探针确认四条路径(TM 菜单、横幅、Token 保存、自动探测)触发时按钮处于 `aria-busy="true"` + `aria-disabled="true"` 且 `.octicon-sync` 命中旋转规则;结束即复位。
8. 手动让 `runFullSync` 进入失败分支(如临时置空 token 或注入抛错的桩)→ 按钮 title 含失败原因。
9. 窄视口:`?tab=stars` 下零痕迹(无自造节点、无 `gsm-*` 类、无内联 display);从 TM 菜单触发同步 → `document` 中不出现 `.gsm-notify-stack`;不出现 live 播报区。
10. 跨断点往返若干轮(桌面→窄→桌面→窄→桌面):网格恒为 1 份、无重复节点、订阅计数回到 0。
11. **a11y 结构断言**:同步前后按钮 `outerHTML` 的**节点结构等价**(仅 `aria-*`/`title` 差异)、文字仍为 `Sync`、按钮宽度不变(`getBoundingClientRect().width` 相同)。
12. **无 SMIL 断言**:产物与运行期 DOM 中 `document.querySelectorAll('animate, animateTransform')` 计数为 0。
13. **动效门断言**:模拟 `prefers-reduced-motion: reduce`(CDP `Emulation.setEmulatedMedia`)下,`.octicon-sync` 的 `animation-name` 为 `none`。

真机部分(只能在真 github.com + 真 TM 上完成,交用户判断,**不阻塞**任务收尾):
